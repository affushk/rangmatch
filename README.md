# RangMatch Maps

A premium, smooth, privacy-conscious map/navigation app built from the ground up, inspired by the interaction quality of leading Chinese map apps without copying their branding or proprietary assets.

## Vision
- Ultra-smooth map gestures and camera animation
- Fast search and place discovery
- Driving, walking and cycling routing
- Traffic-ready layer architecture
- Offline-first map architecture
- Dark/light map themes
- Saved places and trip history
- Voice navigation architecture
- AI-assisted natural-language place search

## Current phase
Phase 1 — foundation and first map experience.

## Planned stack
- React Native + TypeScript
- MapLibre Native renderer
- Vector-tile based map styles
- Provider-agnostic geocoding/routing interfaces
- Secure environment configuration
- Modular feature architecture

## Important
Map data, tiles, geocoding, routing and traffic services must respect their individual licenses, attribution requirements, rate limits and terms of use. No proprietary Google/AMap/Baidu assets are copied.
